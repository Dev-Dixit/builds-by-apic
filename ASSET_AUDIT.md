# ASSET_AUDIT.md

What the reference (https://ayushdhibardesigns.framer.website/) loads, what this site uses instead, and why.
Reference assets were identified from the live DOM, inline `@font-face` rules and image requests
(all served from `framerusercontent.com`). **None of them were downloaded into this project.**

## Licensing position

The reference is another designer's personal portfolio. Its photos, 3D renders, Spline scene, project
screenshots, company logos and custom-font uploads belong to that designer (or to the logo and font owners)
and carry no licence for reuse on this site. The brief says to use originals only "when publicly
accessible and permitted for reuse", so every visual below is either open-licensed or original to this
project. Where the gap is visible, it is listed under *Remaining differences*.

### Generated cloud textures

`node scripts/gen-clouds.mjs` writes `public/images/clouds/*.webp` (needs the `sharp` dev dependency).
Each cloud is a soft-max of spherical lobes on a flat base, outline-roughened with domain-warped fractal
noise and lit as a height field with a lavender underside. Seeds are fixed, so the output is
reproducible. Sizes: 26–85 kB each.

## Remaining differences caused by assets

- The hero is a CSS illustration, not the reference's interactive 3D Spline scene and render.
- Polaroids, project cards, books and timeline logos show placeholders instead of real photos, renders and logos.
- The footer meadow is a vector field, not the reference's photographic grass hill.
- Display text is close to *against* but not identical: wider caps, no swash on the "A" and "y".
